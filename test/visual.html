Node cannot run WebGPU, so the test suite can prove the library is correct but not that anything is visible. This page closes that gap: it renders each effect and measures how much it actually changed the pixels.

Every one of the four times this library appeared broken, the unit tests were green. Twice the shader was fine and the demo's own image or stylesheet made the effect invisible. A number with a floor under it is the only thing that catches that.
